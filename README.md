# 💳 Gobinda ATM Simulator

A simple **ATM Simulator Web Application** built using **HTML, CSS, and JavaScript**.  
This project mimics real ATM functionalities — including **PIN authentication**, **balance checking**, **deposit**, **withdrawal**, **transaction history**, and **PIN change** — all stored locally using the browser’s `localStorage`.

---

## 🚀 Features

✅ **PIN Authentication**
- Default PIN: `1234`
- Secure login screen with option to change PIN anytime.

✅ **Balance Check**
- Displays current account balance dynamically.

✅ **Deposit & Withdraw**
- Deposit or withdraw any amount (limited to available balance).

✅ **Transaction History**
- Shows all deposits and withdrawals with timestamps.
- Option to clear full transaction history.

✅ **Change PIN**
- Update your PIN securely with validation checks.

✅ **Persistent Storage**
- All data (balance, PIN, and transactions) are saved using browser `localStorage`.

✅ **Reset System**
- One-click reset to default settings (PIN, balance, history).

| Technology | Purpose |
